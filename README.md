# Lalaba — Marketing Website

The public-facing marketing site for Lalaba. Deliberately standalone — no API, auth, database, or payment connection to the platform. Public, redacted snapshot — see [Notes on this snapshot](#notes-on-this-snapshot).

## Stack

Next.js · React · Tailwind CSS
