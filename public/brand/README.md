# Lalaba brand assets

The approved Lalaba image assets supplied with this project are installed here and wired through `config/site.ts`.

Current production asset mapping:

- `lalaba-wordmark.png` - horizontal Lalaba wordmark used in the light header
- `lalaba-customer-app-icon.png` - Customer App identity used on dark/footer surfaces and app sections
- `lalaba-customer-app-square.png` - alternate Customer App square artwork
- `lalaba-customer-splash.png` - Customer App splash artwork
- `lalaba-hero-artwork.png` - Lalaba washing-machine artwork used in the hero
- `lalaba-machine-mark.png` - standalone Lalaba washing-machine mark
- `lalaba-partner-app-icon.png` - Partner App icon
- `lalaba-partner-adaptive-icon.png` - alternate Partner App identity artwork
- `lalaba-partner-wordmark.png` - Partner App horizontal wordmark
- `favicon.png` - Lalaba browser icon

Do not redraw, stretch, recolor, or replace these files with unrelated laundry artwork.
